03

Technical Answers

Where are data files written?

Directly to standard local directories as plain UTF-8 CommonMark files without binary wrapping.

Can standard markdown directories be mounted?

Yes. Margin mounts existing folder trees natively without migration scripts or index rebuilds.

Is network connectivity required for core operations?

No. Margin is built for air-gapped workstations and operates autonomously without connection.

How is block attachment preserved across edits?

Content-addressed hashing tracks linguistic paragraph boundaries rather than unstable line offsets.
